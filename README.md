# 🧙‍♂️ Проект «Секреты Темнолесья»

«Секреты Темнолесья» — это фэнтези‑RPG, в которой каждый игрок следует по сюжету своего персонажа, 
выполняет задания и исследует огромный виртуальный мир. В начале нужно выбрать расу, класс и легендарную способность персонажа.
Раса влияет на отношение к герою со стороны других игроков или NPC, класс определяет стиль игры и слабые места, 
а легендарная способность даёт уникальные умения и остаётся неизменной на протяжении всей игры.

🎯 **Цель проекта** — изучить влияние характеристик игроков и их игровых персонажей на покупку внутриигровой 
валюты «райские лепестки», а также оценить активность игроков при совершении внутриигровых покупок.

📋 **Задачи проекта:**
1) Провести исследовательский анализ данных;
2) Решить ad-hoc задачи от коллег из маркетинговой команды игры «Секреты Тёмнолесья»;
3) Сформулировать выводы и рекомендации для бизнеса.

📚 **Источники информации**

В данном проекте использована база данных (БД) онлайн-игры «Секреты Темнолесья».

В БД содержатся данные о 22214 зарегистрированных игроках.

🛠️ **Инструменты и технологии**
- Stack: PostgreSQL;
- Клиент для работы с БД: DBeaver;
- SQL — подготовка данных и агрегаций;
- Использованы JOIN, агрегатные функции, CTE.

В ходе предварительного анализа данных было выявлено:
- Количество уникальных рас - 7;
- Количество уникальных классов персонажей - 13;
- Количество уникальных легендарных умений - 181;
- Количество уникальных эпических предметов - 184.

## 📊 **1. Исследовательский анализ данных**
### **Задача 1. Исследование доли платящих игроков**

Необходимо оценить монетизационную активность игроков в «Секретах Темнолесья» и проверить, зависит ли она от выбранной расы.

1. Рассчитать долю платящих игроков по всем данным:

	a. общее количество игроков, зарегистрированных в игре;

	b. количество платящих игроков;

	c. доля платящих игроков от общего количества пользователей, зарегистрированных в игре.

2. Для каждой расы посчитать:

	a. название расы;

	b. количество платящих игроков этой расы;

	c. общее количество игроков этой расы;

	d. долю платящих игроков внутри расы.

### **Задача 2. Исследование внутриигровых покупок**

1. Собрать статистику по полю "amount" (количество, сумма, мин/макс, среднее, медиана, стандартное отклонение).
2. Найти покупки с нулевой стоимостью: посчитать их количество и долю от общего числа покупок.
3. Для каждого эпического предмета посчитать:

	- общее количество внутриигровых продаж в абсолютном и относительном значениях. Относительное значение 
должно быть долей продажи каждого предмета от всех продаж;

	- долю игроков, которые хотя бы раз покупали этот предмет, 
от общего числа внутриигровых покупателей;
	
	- отсортировать по популярности.

Во всех расчётах (кроме поиска нулевых покупок) исключить записи с нулевой стоимостью.

## ⚡ **2. Решение ad-hoc задач**

В этой части представлены ad-hoc задачи от маркетинговой команды и коллег из аналитического отдела.

### **Задача 1. Зависимость активности игроков от расы персонажа**

Команда хочет понять, насколько «честно» устроено прохождение игры для разных рас. 
Есть предположение, что некоторые расы объективно сложнее, и игроки вынуждены чаще покупать эпические предметы, 
чтобы справляться с контентом. Анализ покупок по расам поможет найти такие перекосы и сделать игровой опыт более 
сбалансированным для всех.

Посчитать такие показатели для каждой игровой расы:

- общее количество зарегистрированных игроков;

- количество игроков, которые совершают внутриигровые покупки, и их доля от общего количества зарегистрированных игроков;

- доля платящих игроков среди игроков, которые совершили внутриигровые покупки;

- среднее количество покупок на одного игрока, совершившего внутриигровые покупки;

- средняя стоимость одной покупки на одного игрока, совершившего внутриигровые покупки;

- средняя суммарная стоимость всех покупок на одного игрока, совершившего внутриигровые покупки.

При написании запроса должна быть проведена фильтрация покупок с нулевой стоимостью.
